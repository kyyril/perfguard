# PerfGuard Evaluation Results

This file is automatically generated by `perfguard eval report`.

## Purpose

The evaluation suite measures PerfGuard's detection quality across different types of performance changes:

- **Detection rate**: proportion of trials where the tool correctly identifies the expected outcome (fail, warn, or pass).
- **False positive rate**: proportion of A/A tests or neutral scenarios where the tool incorrectly reports a regression.
- **Diagnosis hit rate**: when a regression is detected, proportion of cases where the expected function appears in the top K contributor candidates.

## Interpreting Results

### Detection Rate

A detection rate of 90% with confidence interval [68%, 99%] means that in 90% of trials, PerfGuard correctly identified the regression. The confidence interval gives the likely range if the experiment were repeated.

Target: ≥85% for clear regressions (>10% change, 20+ trials).

### False Positive Rate

False positives occur when PerfGuard reports a regression on identical code (A/A test) or neutral refactors. A rate of 5% means 1 in 20 runs incorrectly flags a problem.

Target: ≤5% for fail verdicts, ≤10% for warn verdicts.

### Diagnosis Hit Rate

When a regression is detected, the diagnosis attempts to identify the function responsible. Hit rate measures how often the expected function appears in the top 3 candidates.

Target: ≥60% when pprof data is available.

## Running the Evaluation

```bash
# Run all scenarios
for scenario in eval/scenarios/*; do
  perfguard eval run --scenario "$scenario" --output eval/results
done

# Generate report
perfguard eval report --output eval/results --report eval/RESULTS.md
```
