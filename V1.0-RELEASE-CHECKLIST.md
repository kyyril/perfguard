## Release Notes Template

# PerfGuard v1.0.0

First stable release of PerfGuard, a performance regression detection tool for Go projects.

## What is PerfGuard?

PerfGuard runs benchmarks on base and head code, compares them statistically, and reports whether changes caused performance regressions. It integrates with GitHub Actions to automatically check pull requests.

## Key Features

- **Statistical comparison**: Mann-Whitney U test with confidence intervals
- **GitHub Actions integration**: PR comments with benchmark results
- **Diagnosis**: pprof-based contributor candidate identification
- **Flexible thresholds**: Per-metric warn/fail levels with overrides
- **Baseline storage**: Same-runner or stored baseline modes
- **Evaluation suite**: 8 scenarios measuring detection quality

## Installation

```bash
go install github.com/kyyril/perfguard/cmd/perfguard@v1.0.0
```
